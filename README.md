# Huokaingthara Football Club - Contact & Support Portal ⚽

Welcome to the official **Huokaingthara Football Club** contact and support web portal repository. This project is built as a clean, modular 3-file web application designed to handle club inquiries, training registrations, and partnership requests.

## 🚀 Features

* **Interactive Contact Form:** Captures visitor inquiries with real-time feedback and dynamic validation.
* **Modular Architecture:** Cleanly separated files for structure (`index.html`), styling (`style.css`), and logic (`app.js`).
* **Cyber-Athletic Styling:** Designed with Tailwind CSS and custom glassmorphism components optimized for mobile and desktop screens.
* **Direct Club Information:** Displays official training ground nodes (Olympic Stadium, Phnom Penh) and hotline contact details.

## 📂 Project Structure

huokaingthara_football_club_contact/
│
├── index.html       # Main HTML markup and UI layout
├── style.css        # Custom styles, scrollbars, and animations
└── app.js           # Form submission handling and feedback logic
🛠️ Tech Stack
HTML5 – Semantic document structuring

Tailwind CSS – Utility-first CSS framework CDN

FontAwesome – Scalable vector icons

JavaScript (ES6+) – Client-side form management and UI state control

💻 Getting Started & Installation
Follow these simple steps to run the project locally on your machine:

Clone the Repository:

Bash
git clone [https://github.com/your-username/huokaingthara_football_club_contact.git](https://github.com/your-username/huokaingthara_football_club_contact.git)
Navigate to Project Directory:

Bash
cd huokaingthara_football_club_contact
Run Locally:

Open index.html directly in any web browser (Google Chrome, Microsoft Edge, Safari, Firefox).

Recommended: Open the folder in Visual Studio Code and use the Live Server extension for automated hot reloading.
